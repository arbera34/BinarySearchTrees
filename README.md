
# Binary Search Tree (BST) – Java

## Project Overview

This project implements a Binary Search Tree (BST) in Java to efficiently organize, store, search, and retrieve multimedia data. It was developed as part of my Computer Science coursework at Western University and demonstrates fundamental concepts of data structures, algorithms, and object-oriented programming.

The program uses a Binary Search Tree to manage multimedia records, allowing data to be organized and accessed based on searchable keys.

## Key Features

- **Binary Search Tree Implementation:** Organizes data into nodes containing references to parent, left-child, and right-child nodes.
- **Data Management:** Uses custom Java classes to represent and manage multimedia information.
- **Search Operations:** Supports searching for data stored within the binary search tree.
- **Object-Oriented Design:** Uses encapsulation, constructors, and getter/setter methods to manage data and tree relationships.
- **Modular Code Structure:** Separates tree nodes, dictionary operations, multimedia items, and queries into individual classes.

## Technologies Used

- **Programming Language:** Java
- **Data Structure:** Binary Search Tree (BST)
- **Programming Concepts:** Object-Oriented Programming, Data Structures, Algorithms, Encapsulation

## Project Structure

- `BSTNode.java` – Represents individual nodes in the binary search tree and maintains parent-child relationships.
- `BSTOrderedDictionary.java` – Implements the ordered dictionary using a binary search tree.
- `Data.java` – Stores and manages data associated with tree entries.
- `MultimediaItem.java` – Represents multimedia content associated with stored records.
- `Query.java` – Handles queries and interactions with the data structure.

## Learning Outcomes

Through this project, I strengthened my understanding of binary search trees, data organization, algorithmic problem-solving, and object-oriented software design. I gained hands-on experience building a custom data structure in Java and organizing a larger program into reusable, maintainable classes.
